# Mes Comptes — application Android

Enveloppe Android (WebView) de https://willon1110.github.io/mes-comptes/ : l'appli s'ouvre sans barre d'adresse et se met à jour toute seule, puisqu'elle charge la version en ligne.

- L'APK est construit automatiquement par GitHub Actions à chaque envoi sur la branche `android`.
- Téléchargement : https://github.com/Willon1110/mes-comptes/releases/download/apk/mes-comptes.apk
- La clé de signature (`signing/release.jks`) sert uniquement à signer cet APK ; elle est publique dans ce dépôt. N'installe que l'APK téléchargé depuis la page Releases de ce dépôt.
